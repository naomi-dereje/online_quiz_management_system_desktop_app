QuizMaster – Online Quiz Management System


Overview


QuizMaster is a C# Windows Forms application designed to simplify online quiz creation, participation, and result management for students and lecturers.


Features




Student and lecturer login


Student registration


Quiz management


Online quiz participation


Automatic quiz grading


Result tracking




Technologies




C#


Windows Forms


.NET Framework 4.7.2


Visual Studio




Getting Started




Clone the repository.


Open QuizManagementSystem.slnx in Visual Studio.


Build the project.


Run the application.




Project Structure




Forms/ – Application interfaces


Models/ – Data models


Services/ – Application logic


Helper/ – UI styling and utilities
